Common Issues & Solutions

  • 503 Error: Supabase not configured - Check SUPABASE_URL and SUPABASE_KEY in backend/.env
  • 404 Error: Table doesn't exist - Run the SQL schema in Supabase SQL Editor
  • Empty messages: No data in table - Use the "Send Test Message" button
  • Frontend issues: Check browser console for CORS or network errors
